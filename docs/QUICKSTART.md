# Quick Start

## Prerequisites
- Node.js 20+
- Docker Desktop
- pnpm (recommended)

## Setup
1. `pnpm install`
2. `docker-compose up -d`
3. `pnpm db:push`
4. `pnpm db:seed`
5. `pnpm dev`

## Default Login
- Email: admin@example.com
- Password: admin123

## CLI Commands
- `chimerai add <component>` — Add features
- `chimerai setup <service>` — Configure integrations
- `chimerai doctor` — Health check
- `chimerai update --diff` — Check for template updates
